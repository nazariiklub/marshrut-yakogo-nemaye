# Маршрут, якого немає

Невелика інтерактивна історія українською мовою про нічний трамвай, дивних пасажирів і речі, які ми вирішуємо пам’ятати.

## Як грати

Відкрий [`index.html`](index.html) у браузері та обирай репліки й дії. Гра працює локально: без сервера, акаунтів, інсталяцій та зовнішніх залежностей. Є кілька сюжетних шляхів і три кінцівки.

## Публікація

Це статичний сайт. GitHub Pages може опублікувати його без збірки: достатньо вибрати гілку `main` і кореневу теку (`/`).
